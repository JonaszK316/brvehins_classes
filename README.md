# brvehins_classes

A repo with next brvehins dataset build based on data from Autoseg website

## Installation

0. Clone the repository.
1. Create the conda environment: `conda env create -f enviroment_h2O.yml`
2. Activate: `conda activate brvehins_h2O_en`
3. Install in editable mode: `pip install -e .`
4. Import functions: `from my_package.helpers import sigmoid`
